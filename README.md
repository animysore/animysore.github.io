# Aniruddha Mysore's website

The site is built with Gatsby. The homepage is in [`src/pages/index.js`](src/pages/index.js), its styles are in [`src/style.css`](src/style.css), and the profile photo is in [`content/assets/profile-pic.jpg`](content/assets/profile-pic.jpg).

Use Node.js 24. Run `npm ci`, then `npm run develop` to preview it locally at <http://localhost:8000>. Run `npm run build` to create the production site in `public/`.

Pushes to the `source` branch publish `public/` to the `master` branch for GitHub Pages.
